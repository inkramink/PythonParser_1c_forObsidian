Парсер кода 1с для визуализации в виде графа связей в Obsidian ( https://obsidian.md/ )

Папка input: файлы с кодом 1с
Папка output: файлы с созданными ссылками на соответствующие функции в формата Markdown (.md)
Папка trees: файлы для деревьев вызовов (вверх и вниз)

После создания файлов в папке output или trees, соответствующие папки можно открыть в Obsidian для создания графа.
Удобно пользоваться расширением juggl ( https://github.com/hemile/juggl ) для более комфортной работы с графом. 
В проекте это папка juggl. В Obsidian -> Настройки -> Сторонние плагины справа от текста "Управлениями плагинами" можно открыть папку и скопировать туда папку juggl из проекта

Функционал:
1. Создать файлы .md для всех функций приложенных файлов
2. Построить дерево вызовов вниз от текущей функции из данных приложенных файлов
3. Построить дерево вызовов вверх от текущей функции из данных приложенных файлов
4. Удалить функцию и все дерево вниз от нее (функция из дерева вниз не удалится, если ее вызывает еще какая-то функция)
5. Смена директорий для папок input, output, trees
